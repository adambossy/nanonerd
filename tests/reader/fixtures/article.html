Harnesses, Briefly

By Jane Doe

An agent harness is the scaffolding around a model: the tool loop, the context assembly, the stop conditions, and the evaluation hooks that let a team iterate on behavior without retraining anything. This fixture exercises every construct the reader has to preserve on the way from a rendered page to a list of chunks, so the prose here is only padding around the interesting markup that follows.1

Code

The harness calls tools in a loop until the model stops asking for them, and each tool result is appended to the context before the next generation step, which is the entire trick and also the whole difficulty.

def loop(model, tools, ctx):
    while True:
        step = model(ctx)
        if step.done:
            return step
        ctx.append(tools[step.name](step.args))

Keep the stop condition explicit; implicit stops are where harnesses rot.
